# مشروع تطبيق مكتبة الأحمدي

هذا مشروع أولي بسيط لتطبيق أندرويد:
- عرض منتجات تجريبية قابلة للتعديل داخل `lib/main.dart`
- تصنيف أدوات مدرسية وألعاب وهدايا
- سلة مشتريات وحساب إجمالي
- إرسال الطلب عبر واتساب إلى الرقم 01141086737

## استخراج APK دون تثبيت Android Studio
1. أنشئ حساباً على GitHub.
2. أنشئ مستودعاً جديداً (New repository).
3. ارفع محتويات هذا المجلد إلى المستودع، مع الاحتفاظ بالمجلد `.github/workflows`.
4. افتح تبويب Actions.
5. اختر Build Android APK ثم Run workflow.
6. بعد نجاح التشغيل افتح نتيجة التشغيل، وانزل إلى Artifacts وحمّل `al-ahmadi-library-apk`.
7. فك ضغط الملف لتحصل على `app-release.apk`.

ملاحظة: هذه نسخة أولية بمنتجات وأسعار تجريبية. لا يوجد مخزون أو لوحة تحكم أو دفع إلكتروني أو استقبال طلبات داخل نظام للمحل؛ الطلب يُرسل برسالة واتساب بعد مراجعة السلة.
